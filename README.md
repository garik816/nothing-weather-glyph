# Weather Glyph for Nothing Phone (4a) Pro

Glyph Toy для матрицы 13×13: поочерёдно показывает пиктограмму текущей погоды и
температуру в градусах Цельсия. Погода загружается из Open-Meteo по приблизительной
геолокации; последнее успешное значение хранится локально.

## Возможности

- актуальная погода и температура на Glyph Matrix 13×13;
- автоматическое фоновое обновление с локальным кэшем;
- отдельные дневные и ночные пиктограммы;
- бесконечные погодные анимации с настраиваемыми яркостью, скоростью и таймаутами;
- предпросмотр экранов Glyph прямо в приложении;
- каталог всех погодных анимаций с программным и аппаратным предпросмотром;
- переход из приложения в системное меню выбора Glyph Toys.

## Сборка

```bash
./gradlew assembleDebug
```

На ARM64-хосте, где стандартный `aapt2` из Android SDK не запускается, путь к
совместимому бинарнику можно передать локально, не записывая его в репозиторий:

```bash
./gradlew -Pandroid.aapt2FromMavenOverride=/path/to/aapt2 assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Установка и запуск

1. Установите APK на Nothing Phone (4a) Pro.
2. Откройте приложение, разрешите приблизительную геолокацию и нажмите
   «Обновить погоду».
3. Откройте `Settings → Glyph Interface → Glyph Toys` и добавьте `Weather`.

Для отладки GDK можно временно включить режим разработчика:

```bash
adb shell settings put global nt_glyph_interface_debug_enable 1
```

В `AndroidManifest.xml` используется тестовый `NothingKey`. Для публикации замените
его выданным Nothing ключом, если целевая версия Nothing OS всё ещё его требует.
